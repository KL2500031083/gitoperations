# Happy Birthday, Amma

A single-page digital birthday card, memory book, and love letter made with vanilla HTML, CSS, and JavaScript.

## Open it

Double-click `index.html` to open it in a browser. No build step or installation is needed. The same folder can be published directly with GitHub Pages.

## Add photos

Put your own image files in `assets/images/` using these exact names:

- `mom1.jpg`
- `mom2.jpg`
- `mom3.jpg`
- `mom4.jpg`
- `family.jpg`
- `swimming.jpg`
- `rowing.jpg`
- `sports1.jpg`
- `sports2.jpg`
- `nationals.jpg`

JPG, PNG, and WebP images work. If a file is missing, the site automatically displays a soft `Add your memory here` placeholder instead of a broken image.

## Add music

Music controls are not included, so the page stays quiet and works without audio permissions.

## Customize the page

- Edit the letter paragraphs and headings in `index.html`.
- Change colors, typography, spacing, and animation in `style.css`.
- Change interaction behavior in `script.js`.
- Google Fonts are loaded when online, with elegant local fallbacks when offline.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload every file and folder in this project.
3. Open the repository's **Settings**, then **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. GitHub will provide a shareable website URL after deployment.

The project uses only HTML5, CSS3, and browser JavaScript, so it is ready for static hosting.
